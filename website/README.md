# Octypo website

The source of [octypo.com](https://octypo.com): a React page built with Vite and
prerendered to static HTML.

```bash
npm install
npm run dev
```

`npm run build` writes the site to `dist/`.

## Not included

The fonts, images and videos are not in this repository, and the page falls back to
system fonts and empty media slots. To run it with your own, place them in `public/`.
The MIT license covers the code here, not the Octypo brand assets.
